# Support

Thanks for your interest in wow-repo.

## Get help

- **Questions about the code**: open a
  [discussion or issue](https://github.com/aniruddhaadak80/wow-repo/issues)
- **Something looks broken**: file a
  [bug report](https://github.com/aniruddhaadak80/wow-repo/issues/new?template=bug_report.yml)
- **A registry entry is wrong or missing**: use the
  [registry entry form](https://github.com/aniruddhaadak80/wow-repo/issues/new?template=registry_entry.yml)
- **Security concerns**: see [SECURITY.md](./SECURITY.md), report privately

## What to expect

This is a demo site maintained in spare time. Responses are best-effort.
Issues with a reproduction (route, browser, screenshot) get answered fastest.

## What is not supported

- The install commands in the registry are samples, not a package distribution
- The benchmark numbers, agent org, and discovery entries are sample data
  labelled as such in the UI; do not cite them as real measurements
- Third-party projects linked from the registry are not affiliated with this
  repository
