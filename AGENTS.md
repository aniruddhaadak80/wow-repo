## Rules for agents working in this repo

> Everything above this line is generated by `next dev`. Everything below is ours.

### Commands

```bash
bun install            # or npm install
bun run dev            # http://localhost:3000
bun run typecheck      # tsc --noEmit
bun run lint           # eslint
bun run test           # vitest run
bun run format:check   # prettier
bun run check          # all of the above plus build
```

### Conventions

- Server Components by default. Anything with state, motion, or a DOM event listener is a `"use client"` leaf and nothing else.
- Data lives in `content/*.ts` as typed records and is read through `lib/*.ts`. Never fetch static content from a component.
- Numbers that are not measurements must be labelled as sample data in the UI, not just in a comment.
- One accent color, one radius scale, one z-index scale (`lib/constants.ts`). Add to the scale before inventing a new `z-*` value.
- Animation: `transform` and `opacity` only, `useReducedMotion()` everywhere, and a reason you can say in one sentence before you add it.
- No em-dashes in any user-visible string. Use a colon, a comma, or two sentences.

### Before you say a change is done

`bun run check` must pass, and anything you added to `content/` needs a test in the matching `*.test.ts` next to it.
