# Security Policy — wow-repo

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| main    | ✅ Yes (current)   |

## Reporting a Vulnerability

Report security issues privately to the maintainer (no public GitHub issue).
Include reproduction steps, affected versions, and impact.

## Scope

In scope: `wow-repo` source, `app/`, `content/`, `.github/workflows/*`.

Out of scope: third-party analytics/Lighthouse targets.

Thank you for helping keep wow-repo performant and safe.
